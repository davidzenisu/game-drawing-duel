There should be the option to start a "one-off" server session which follows the same rules as any "generic" server (see [Initial Setup](./initial-setup.md)) and then goes through the following phases back-to-back with timers on each day:


~20 minutes

- Setup: 5 min
- Day 1: Title (1 min)
- Day 2: Title + Drawing (2 min)
- Day 3: Title + Drawing + Boost (3 min)
- Day 4: Drawing + Boost + Fighters (3 min)
- Day 5: Boost + Fighters + Voting (2 min)
- Day 6: Fighters + Voting (1 min)
- Day 7: Voting (1 min)

- Later: Day 7: Finale (3 min) ?
